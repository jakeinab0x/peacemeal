## peacemeal
TLDR; Meal planning and budgeting app. Final project for the [DJ4E](https://www.dj4e.com/) course.

# Full concept
This app will allow users to search a [static nutrition dataset](https://www.kaggle.com/datasets/tharunmss/nutritional-breakdown-of-foods/data) to create and categorise meals as breakfast, 
lunch, dinner, or snacks, and arrange them into a comprehensive weekly schedule that automatically sums up daily 
and weekly calorie totals. Once the meal plan is finalised, the app generates a dynamic grocery shopping list where 
users can manually input the actual prices paid for individual items, enabling them to track food cost fluctuations 
and manage their grocery budget over time without the complexity of an automated digital pantry or external web scrapers.
